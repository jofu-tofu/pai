# Structured problem solving

Use the current host's tools. This folder has no runtime, hooks, settings, memory service, or required sibling skills.

State the requested outcome and constraints, inspect the relevant evidence, choose an approach, implement it, and verify the result against the outcome. Match formality to the task. Keep a short checklist for work with several steps; use a project-local Markdown record only when continuity helps. Mark untested criteria as untested. Explain material uncertainty and any next action. Respect the host's permission rules and the user's requested answer format.

## Examples

Ask for the PAI workflow with the relevant task, input files and output destination. Apply the local method using available host tools, then report the result and evidence; identify any unavailable capability.
