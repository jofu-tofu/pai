Structured knowledge lenses for C# and .NET. Each dimension groups related rules with deep context for a specific concern.

| ID | Dimension | File | Load When |

| CS2 | Null Safety | NullSafety.md | Nullable context, null guards, required properties, null returns |

| CS4 | Member Design | MemberDesign.md | Method signatures, immutable returns, visibility, maintainability |
