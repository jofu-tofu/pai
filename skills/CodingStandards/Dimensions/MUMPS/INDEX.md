# MUMPS Dimensions

Structured knowledge lenses for MUMPS / Chronicles coding. Each dimension groups related rules for one concern, with full rule content inlined.

## Dimensions

| ID | Dimension | File | Load When |
|----|-----------|------|-----------|
| M1-M3 | Standards | Standards.md | ANSI compliance, syntax formatting, naming conventions, portability |
| M4-M6 | Safety Patterns | SafetyPatterns.md | Variable scope, data/globals access, concurrency, error traps |

## Default

Load **Standards (M1-M3)** for any MUMPS task. Add Safety Patterns based on the review goal.
