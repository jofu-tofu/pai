# React Dimensions

Structured knowledge lenses for React/Next.js. Each dimension groups related rules with deep context for a specific concern.

## Dimensions

| ID | Dimension | File | Load When |
|----|-----------|------|-----------|
| R1 | Architecture | Architecture.md | Component design, API design, composition patterns, props interfaces |
| R2 | Data Fetching | DataFetching.md | Async patterns, waterfalls, caching, Suspense, SWR, API routes |
| R3 | Server Components | ServerComponents.md | RSC patterns, server cache, auth actions, serialization |
| R4 | Rendering & Performance | RenderingPerf.md | Re-render optimization, hydration, content visibility, transitions |
| R5 | Bundle Size | BundleSize.md | Import optimization, dynamic loading, preloading, tree shaking |
| R6 | JavaScript Performance | JavaScriptPerf.md | Loops, data structures, DOM batching, caching, advanced patterns |

## Default

Load **Architecture (R1)** for any React task. Add task-specific dimensions on top.
