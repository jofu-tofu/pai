# Setup

Read `PORTABILITY.md`. Copy the entire folder. Use host-provided tools for model, agent, browser and search operations. Install only the optional packages declared in this folder.

Set `TELOS_DIR` to your existing notes directory before using tools or templates. Without it tools use `./telos` relative to the invoking process; no existing vault is discovered or modified automatically. Optional `TELOS_TIMEZONE` sets log timestamps (UTC by default).
