# Format Selection

Use this matrix before building slides.

| Condition | Prefer HTML | Prefer PPT |
|---|---|---|
| Rapid drafting and sharing by link | Yes | No |
| Executive or client-facing formal meeting | Sometimes | Yes |
| Strict corporate template required | No | Yes |
| Lightweight single-file handoff | Yes | No |
| Offline editing in Microsoft Office | No | Yes |
| Interactive demos during delivery | Yes | Sometimes |
| Team editing inside PowerPoint | No | Yes |

## Default Rules

1. If audience and venue are unclear, start with HTML for speed.
2. If stakeholders expect editable Office deliverables, choose PPT early.
3. For heavy interactivity, author in HTML and produce PPT summary for distribution.
4. For executive final delivery, provide PPT even if HTML is source.

## Input Checklist

- Audience: who will decide based on this deck?
- Objective: inform, persuade, or request approval?
- Venue: browser, webinar, projector, or file exchange?
- Editing model: single author or multi-editor collaboration?
- Brand constraints: strict template or flexible visual language?
