# Quality Checklist

## Message Quality

- One explicit takeaway for the full deck.
- One primary idea per slide.
- Claims supported by evidence or concrete examples.
- Narrative arc flows from context to ask.
- Slide count matches speaking time budget.

## Visual Quality

- Consistent spacing, alignment, and typography.
- Readable contrast and type size at presentation distance.
- Charts prioritize signal over decoration.
- Visuals support the argument, not filler aesthetics.
- Text density stays within presenter-readable limits.

## Format-Specific Checks

### HTML
- Deck loads without console errors.
- Keyboard navigation works across slides.
- Layout remains stable at common projector resolutions.
- Dependencies and run instructions are explicit.
- Backup static export path is documented.

### PPT
- File opens in PowerPoint without repair warnings.
- Theme and fonts render as intended.
- Speaker notes exist where presenter support is needed.
- Animations are intentional and minimal.
- Output file size fits distribution channel constraints.

## Delivery Readiness Gate

- [ ] Opening slide states objective and context.
- [ ] Closing slide states the ask or decision.
- [ ] Evidence sources are current and attributable.
- [ ] Format-specific checks are complete.
- [ ] Backup export is prepared.
