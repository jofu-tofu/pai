# meta-plan

Frame the decision and constraints. Decompose the problem, generate several meaningfully different approaches, compare them against explicit criteria, challenge the strongest candidate, and produce a recommendation with risks, switching conditions and executable next steps. Research unknown facts using host tools when needed. Use task-specific role passes or authorized agents if useful; no other thinking skill is required. Scale the effort to uncertainty and reversibility, and separate planning from authorization to deploy or publish.
