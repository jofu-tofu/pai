# ProcessInput Workflow

> **Trigger:** "process input", "run task", "handle input"

## Reference Material

- None.

## Purpose

Process user input and execute the requested task. Acts as the primary entry point for task execution in the TestTarget skill.

## Workflow Steps

### Step 1: Read Input

Read the user's request and determine what needs to be done. Identify the type of task and any parameters provided.

### Step 2: Execute

Perform the requested action based on the parsed input.

### Step 3: Report

Summarize what was done and present results to the user.
